# 橘汁影视客户端 · 项目说明

## 一、这是什么

橘汁影视（原 App 为 Android 原生，本仓库为 **Flutter 重写版**）的第三方客户端。
不设账号体系，所有用户数据（下载索引、观看记录、弹幕开关）**只保存在本机**。

功能范围：

| 模块 | 能力 |
| --- | --- |
| 发现 | 推荐 / 电影 / 电视剧 / 综艺 / 动漫 / 短剧 六个分类，分页加载 |
| 详情 | 剧集信息、演员、简介、多线路（源）与全部剧集列表 |
| 播放 | MP4 / HLS、倍速（0.5x–2.0x）、音量、全屏、投屏位预留 |
| 播放增强 | 全屏内选集 / 换源 / 自动连播下一集 / 弹幕滚动 |
| 下载 | MP4 直下、HLS 分片并发下载、AES-128 解密、暂停续传、断点恢复 |
| 我的 | 下载管理、最近观看、继续观看、清空记录、版本信息 |

## 三、核心模块

### core/protocol.dart
protobuf 手工编解码（`PbReader` / `PbWriter`），不引入 protobuf 运行时。
源站所有业务请求体都是 protobuf，但字段很少、结构稳定，手写读写比生成代码更轻。

### core/api.dart
- `_buildPublicParams()`：AES-256-ECB 加密 + RSA 签名，产出 `publicParams` 请求头。
- `JuziApi.playUrl(source, path)`：把「源标识 + 剧集 path」解析成真实播放地址。
- `JuziApi.isDirectUrl()`：判断 path 是否已经是可直接播放的直链。

### core/download.dart
下载器，承担了项目里最复杂的逻辑：
- **类型嗅探**：源站常把 m3u8 标成 `image/png` / `octet-stream`，不能信 Content-Type，
  读首字节嗅 `#EXTM3U` 才可靠。
- **HLS 分片并发**：默认 6 并发，逐片落盘到 `.parts/`，完成后按序拼接。
- **AES-128 解密**：`#EXT-X-KEY` 出现时必须解密，否则拼出来是密文。
- **分片齐备跳过网络**：playlist 带时效 token，全部下完后再请求会 403；
  因此分片已齐时直接拼接，不再访问网络。
- **原子索引**：`.tasks.json` 写 `.tmp` 再 `rename`，避免断电写坏。
- **目录探针**：外部存储不可写时自动回退内部私有目录。

### core/danmaku.dart + widgets/danmaku_overlay.dart
弹幕接口 `POST /api/danmu/getMovieDanmuList.do`，参数 `movieId`（剧集 id）、
`movieKey`（**集数序号，不是剧名**）、`danmuStart`、`danmuEnd`；返回明文 JSON，
`danmuTime` 单位是**秒**，颜色在 `danmuAttrs` 的 `c` 键。

渲染层用 `Ticker` 每帧驱动，只重绘本层（不 setState 整页），关键设计：
1. 读 `controller.value.position` 作为唯一时间源，与倍速/seek 天然同步；
2. seek 检测：位置跳变 > 2 秒即清空在场弹幕并重新入队；
3. 轨道分配：选「最久未占用」的轨道，避免同行重叠；
4. 暂停冻结、单帧最多发射 3 条防刷屏。

## 四、已知约束

- **不做弹幕发送**：没有账号体系，接口也不支持匿名投递，只做只读展示。
- **换源可能失败**：部分源限制线路或分片失效，此时给出明确提示并引导「重新解析」，
  不静默卡住。
- **本地播放弹幕依赖入队时记录**：v1.0.0 下载的老任务没有剧集标识，
  播放时不显示弹幕（也不误报「暂无弹幕」）。
- **版本号双处维护**：`pubspec.yaml` 的 `version` 与 `lib/core/version.dart` 需同步修改。

## 五、开发与构建

```bash
export PATH="/c/flutter_sdk/bin:$PATH"
cd code/flutter_app

flutter analyze          # 静态检查，应当零问题
flutter build apk --release
# 产物：build/app/outputs/flutter-apk/app-release.apk
```

打包后归档：

```bash
cp build/app/outputs/flutter-apk/app-release.apk \
   ../../dist/v<版本号>/Juzi-v<版本号>-release.apk
```

实机验证（模拟器 `emulator-5554`）：

```bash
cd code/tools
./ui.sh desc              # 列出可点击元素
./ui.sh tapx "我的"       # 按描述模糊点击
./ui.sh shot out.png      # 截图
```

> 注意：Windows 下 adb daemon 会在命令之间被回收，`ui.sh` 每条命令内部
> 都会重新 `start-server` 并轮询 `get-state`，不要绕过它直接调 adb。

## 六、本版变更（v1.0.1）

1. **启动白屏修复**：`main()` 不再 await 磁盘恢复，改为后台 `unawaited`；
   `launch_background` 与 `Theme.Black` 改深色，消除白屏闪烁。
   实测 release 包冷启动 3.7s（原 debug 包 22s）。
2. **播放器改版**：进度条在上、操作行在下；倍速竖排浮层、音量竖排滑杆。
3. **全屏增强**：右侧「选集 / 换源」面板，剧集自动连播（3 秒倒计时可取消）。
4. **弹幕**：接口接入 + 滚动渲染 + 开关，全屏/竖屏/本地播放均支持。
5. **弹幕开关持久化**：写 `shared_preferences`，跨启动保留。
6. **本地播放弹幕**：下载任务记录 `dramaId` / `episode` 并随索引持久化。
7. **「我的」页修复**：版本号改为单一来源常量；下载目录状态改为订阅通知，
   建好后自动从「未创建」变为「已设置」。
