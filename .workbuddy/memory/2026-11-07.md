### 关键突破：publicParams 加密在 native 层
- 生成点 `o00O0oO/o00O0000.java:115`：
  `BaseNativeJNI.getInstance().method01(gson.toJson(paramsMap))`
- `publicParams` 走 native JNI（`libBaseNativeJNI.so`），不在 Java 层 → 之前用 Java 层抓到的 8 枚密钥全部解不开，原因在此。
- 明文 606 字节 → PKCS7 补 2 → 608 字节；密文 608 字节（38 块）。**标准块加密，无压缩**。首块恒定 = 6 条明文前 16 字节相同。
- so 用 `JNI_OnLoad` + `RegisterNatives` 动态注册，无 `Java_com_hive_*` 符号；含防重打包证书指纹白名单两枚（`0C:7D:...:AA:24`、`C9:FA:...:FE:F5`）。
- **结论：不需要解密——hook `method01` 入参即得明文 JSON。**

### 环境踩坑（复用要点）
- adb 每次 Bash 调用会重启 daemon → `connect`+`forward`+`frida` 必须同一条命令
- Git Bash 会转换 `/data/local/tmp` → 必须 `MSYS_NO_PATHCONV=1`
- frida 17.x 已移除 `--no-pause` 参数
- 日志重定向用 shell `>`，不用 `-o`（强杀时缓冲不刷盘）
- `curl` 报 `CRYPT_E_REVOCATION_OFFLINE` 是本机 schannel 问题，加 `--ssl-no-revoke` 即可
