### 关键修正：旧 README 的 Windows 排障说法是错的
原文写「Flutter 判断 VS 是否安装，是靠执行 `reg query` 查注册表」。
实测 Flutter 真正的判断依据是
`vswhere -requires Microsoft.VisualStudio.Workload.NativeDesktop`，
`reg query` 只用于读 Windows 版本号。三种成因：
1. 真缺组件
2. **编译器装着但缺 NativeDesktop 标记**（本次实际情况，最隐蔽）
3. `reg.exe` 被拦

顺带补了手动 CMake 的三个坑：清大小写代理变量、必须 `--install --prefix`
（`--target INSTALL` 会拿到未展开的 `$<TARGET_FILE_DIR:zhuiju>`）、
`flutter_assemble` 被判 up-to-date 导致 AOT 不重跑。
