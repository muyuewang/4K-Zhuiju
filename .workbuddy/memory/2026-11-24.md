### 关键技术结论（容易重踩）
- **旧 cKey 8.1 直调 get_live_info 已失效**：18 种 guid/platform/代理组合全部 HTTP 401（APISIX 网关，空 body），换 header 无效。根因是央视频 2025 年把签名升级到 WASM（`assets/2025/wasm/hls.cmg.js?ver=250813` + cmg.worker.js）。公开资料（恩山论坛 tid-8354943、博客园 xuchunlin）里的 key/iv/salt 是 2024 年的，本地复刻过不了网关。
- **可用方案：CDP 抓流**。用 Edge/Chrome headless 打开直播页，页面 JS/WASM 自己算签名，CDP 在网络层旁听抓出真实 m3u8。实测 CCTV-1 抓到，m3u8 带 `ysign/ytime/svrtime/guid/pid` 参数，**无需 Cookie 直连 200**，返回标准 HLS，分片是相对路径（播放器须以 m3u8 URL 为 base，所以用 stream_url 端点拿 URL 而非文本）。
- 签名 URL 有时效，relay 做 60 秒缓存，客户端 TTL ≤60 秒。
- 两套 ID：cnlid（接口用，CCTV-1=2022576803）vs pid（网页用，CCTV-1=600001859），channels.json 都存了。
- CDP 依赖：`websocket-client`（已装 1.9.2）。Edge headless 走 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`。
