## 数据源插件化可行性评估（dart_eval 实测）

**背景**：用户要求源支持 URL 导入、远程执行 Dart（类似 TVBox 远程 JS），避免源规则变更就得发版。

**做法**：在 `.tmp2/eval_spike/` 建探针工程（dart_eval 0.8.5），写了 spike1–17 共 17 轮探针，逐项实测能力边界。

### 决定性结论

方案可行，但**必须改成「宿主 fetch + 插件同步解析」**，因为 dart_eval 的 async/await 不可用，而现有 `DataSource` 接口全是 Future。

### dart_eval 真实能力边界（全部实测，非推测）

**致命 —— null 语义是坏的（最危险，静默出错）**：
- `x == null`（x 确实 null）→ 返回 **false**
- `x != null`（x 确实 null）→ 返回 **true**（语义反向）
- `x ?? "默认"`（x 是 null）→ 返回 **null**（不兜底）
- `x is String`（x 是 null）→ **运行时崩溃** `type 'Null' is not a subtype of '$Value'`
- `x.toString()`（x 是 null）→ **运行时崩溃**
- `x == null ? a : b` → **运行时崩溃**

**语法不支持**：`continue`、标签跳转、`switch 表达式`、扩展方法、`Map<K,V>()` 构造器、`Map.forEach`、集合 if/for、`!expr`（dynamic 类型）、`base64Decode`、`import package:*`
**语法支持**：索引 for、for-each、break、switch 语句、try/catch、map/list 字面量、RegExp、jsonDecode/Encode、split/substring/replaceAll/padLeft、Uri.parse
**注意**：字符串方法**必须静态类型标注为 String**，否则报 `Unknown method int.trim`

**异步**：裸 `async` **静默返回 null**（不报错，最难查），`Future.value` 编译失败

**沙箱（关键，决定方案能过安全关）**：
- `Runtime` **默认零权限**
- `dart:io` 可以 import，`File` 可以构造，但 `readAsStringSync`/`writeAsStringSync` 被 `Permission 'filesystem:read/write' denied` 拦住
- `HttpClient().getUrl()` 被 `Permission 'network' denied` 拦住
- `dart:isolate`/`dart:ffi`/`dart:mirrors`/`package:*` 编译期就拒绝
- 权限可粒度授予（`NetworkPermission.url(...)` / `FilesystemReadPermission.directory(...)` / `ProcessRunPermission.namedExecutable(...)`）——**我们的策略是一个都不给**

**性能**：单份冷编译 15–25ms、19 份 290–483ms、单次解析 10 条 0.9–1.4ms、1000 次 while 3ms、10 万次 while 151ms。`executeLib` 同步阻塞不可中断，**必须独立 isolate + 3s 超时强杀**。

### 架构方案（已写入 doc/源插件化评估.md）

3 个同步接口，全部返回 JSON 字符串（不用 Map，避免 `$Map<$Value,$Value>` unwrap 嵌套）：
- `listItems(body, srcId, gs, gi)` → 列表
- `detailItem(body, srcId, gs, gi)` → 详情含多线路
- `step(ctxJson, gs, gi)` → 多轮状态机（`{"need":"fetch","url":...}` / `{"done":...}`）

核心设计：宿主注入 `gs`/`gi`/`gl` 三个取值闭包，**永远返回非 null**（`""` / `0` / `[]`），插件内一律不碰可能为 null 的值，从而把 null 缺陷降级为无关项。已实测 190 次解析全成功。

### 迁移范围

19 个源中 13 个（68%）可插件化（12 个 `MacCmsApiSource` + 1 个 `MacCmsSource`，`maccms_api_source.dart` 1159 行零处站点特判）；6 个必须保持内置：橘汁（AES+protobuf+RSA，`package:crypto` 不可 import）、4K影视/极速/云影/低调（`CdndefendGate` + PoW，需 async + 自定义 HTTP 栈）、看剧（两阶段 resolve，可能可走多轮 step 但要实测定）。

### 探针编写陷阱（踩过的坑，避免重复）

- `$Map<String,String>.wrap` 会把值全转 String，导致插件内 `stage == 1` 整数比较永假
- `$Map` 的参数不要嵌套 `$String`/`$int`，会污染；需要类型语义时改用 JSON 字符串传参
- Dart 源码里的 `$` 必须写 `\u0024`，否则被 dart_eval 当字符串插值符
- 闭包参数类型必须是 `Function`，`dynamic` 不可调用
- 诊断闭包时 Dart 侧直接调需要 `Runtime` 实例，改用 eval 代码内调用
