不假装能播。服务端接通后不用改代码。

### 教训

- `urllib` 在这台机器上走 `127.0.0.1:5793` 代理会直接 SIGTERM，改用 `curl` 子进程。
- Windows 版 python 不认 `/c/...` 路径，要 `C:/...`。
- b64 解前缀盐时**不能按字符下标切**（盐是二进制，在 base64 解码之后才出现），
  按「整体 decode → 扫内层找可解段」才稳。
