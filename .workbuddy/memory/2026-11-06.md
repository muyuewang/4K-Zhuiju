
## vivo V2020A (vivo S7) root 可行性实测
- 设备: V2020A / PD2020, Android 10 (SDK 29), lito (SM7250 骁龙765G), OriginOS Ocean
- fingerprint: vivo/PD2020/PD2020:10/QP1A.190711.020/compiler05211144:user/release-keys (非标准零售 build，compiler 前缀)
- 安全补丁 2022-08-01, 内核 4.19.81-perf+
- 三处硬阻断实测:
  1. adb root → "adbd cannot run as root in production builds" (ro.secure=1, ro.debuggable=0)
  2. adb remount → "Not running as root"
  3. adb reboot bootloader / reboot fastboot → 设备从 USB 消失并自动回系统, fastboot devices 始终无输出 (vivo 定制 BL 拒绝进入 fastboot)
- 解锁状态: ro.boot.vbmeta.device_state=locked, ro.boot.flash.locked=1, verifiedbootstate=green, sys.oem_unlock_allowed=0
- 结论: 该机无官方 BL 解锁通道，adb 侧无法提权；真 root 需第三方 EDL/9008 强刷
- 替代方案: Shizuku (adb 授权, 免 root) / VMOS 类虚拟机

## 橘汁 APK (com.asjdhjhd.mgd.p3 v3.0.7.0) 动态分析 — 雷电9 模拟器
- 雷电9: D:/leidian/LDPlayer9/dnplayer.exe, Android 9/SDK28, x86_64, rootMode=true, SELinux Permissive
- adb 连模拟器: adb connect 127.0.0.1:5555 (emulator-5554 会 offline)
- Frida 关键坑: -H 必须指向 27042 且需先 `adb -s 127.0.0.1:5555 forward tcp:27042 tcp:27042`;
  每次 Bash 调用会重启 adb daemon 导致 forward 丢失 → 连接/forward/注入必须写在同一条命令里
