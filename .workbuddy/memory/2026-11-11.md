## v1.8.2 榜单续拉死角

### 修复
榜单翻页只挂在 ScrollController 监听（`pixels > max - 600`），
若某页内容装不满一屏则 maxScrollExtent=0，滚不动 → 监听永不触发 →
后面几页永远出不来。

修复：每次加载后 post-frame 检查 maxScrollExtent，装不满就续拉；
记录 `_lastAdded`，为 0 时立即停止（防服务端只回重复分区导致无限请求）。

### 重要修正：我最初的高度估算错了
凭「3×208 + 内边距 ≈ 700px」判断手机上必然卡死 —— **错的**。
实测（flutter_test 里 maxScrollExtent 反推）：视口 760、3 分区 → max=253
→ 内容实际约 **1013px**，单分区约 338。主流手机逻辑高度约 800，
首屏本来就能滚，原逻辑可用。
真正会踩的是：高视口（平板/TV）或某页只回 1~2 个分区。
教训：不要用估算值当前提下结论，先加诊断打印量真实值。

### 测试写法两个坑（已写进测试文件头）
1. **`SizedBox(height: 1100)` 撑不起视口**：flutter_test 默认画布
   800×600，SizedBox 被父级约束压回 600，前提不成立。
   必须 `tester.view.physicalSize` + `devicePixelRatio=1.0` + `addTearDown(reset)`。
2. **`pumpAndSettle` 会 timed out**：底部 CircularProgressIndicator 是
   无限动画，装不满一屏时它就在屏上，永远等不到静止。
   改用固定帧数 `tester.pump(Duration(ms:50))` 循环。

## v1.8.3：官方线可播了（游客会话）+ Cookie 提取 bug

### 用户实测反馈驱动的结论翻转
用户切到 kanju 后反馈「官方源画质好、普通源很卡甚至无法播放」，
并提到「不是能游客登录么」。此前 v1.8.1 把官方线判为次优（因为 401），
这个判断在接入游客会话后不再成立，本版翻转为**默认官方优先**。

### 游客会话接口（已验证）
`POST /v1/users/anonymous` body `{"anonymous_id": "32位hex"}`
→ **HTTP 201**（不是 200！）+ `Set-Cookie: ai_movie_session=...`，有效期一年。
前端代码位置：`assets/movie-card-runtime-*.js` 里 `auth:"none"` 那次调用。

实测结果（三轮）：
1. 不带会话：沙海第 10/19/28/37/46 集官方线 10 次全 401
2. Python 带会话：沙海 8 集抽样 16/16、庆余年 6 集 27/27，均 100%
3. Dart 真实路径首次仍 401 → 定位到下方 Cookie bug

### 关键 bug：同名 Cookie 取了第一条（空值）
接口一次下发 **5 条同名 `ai_movie_session`**，前 4 条是空值 + Max-Age=0
的删除指令，第 5 条才是真会话。取第一条 = 主动删会话 → 所有官方线静默 401。

这个 bug 的隐蔽点：不抛异常，错误码和「源站改版」「密钥过期」完全一样。
Python 探针发现不了（http.cookiejar 自带同名覆盖语义）。
修复：取最后一条值非空且未过期的；抽成 `KanjuSource.pickSessionCookie`
静态纯函数 + 6 项单测。

### 线路偏好改造
删除 `kRankResolve` / `kRankDirect` 固定档位，改为 `kRankPrimary` /
`kRankSecondary` + `LinePreference{officialFirst, directFirst}` 驱动。
`lineRankOf` / `lineRankOfAll` / `sortedSourceNames` / `pickDefaultSource` /
`switchCandidates` 全部增加 `pref` 具名参数，默认 officialFirst。
设置入口：我的 → 线路优先级（`profile_page.dart` `_pickLinePref`）。

### 测试写法注意
测试断言改成「双偏好对照」而非具体数值——数值是实现细节，
翻转默认值时不该连测试一起改。只断言两种偏好下顺序互换。

  "C:\\Users\\fengxin\\WorkBuddy\\vivos7-copy" \
