## 发布通道经验（复用）

- `code/tools/make_release.py`：TAG/NAME/ASSETS/NOTES 是硬编码，每次发布前必须改版本号
- 无 gh CLI，走 `git credential fill` 取 token + `--proxy http://127.0.0.1:7897` + curl
- 所有 git/curl/python 命令必须 `env -u` 摘掉 http_proxy/HTTP_PROXY 等，否则 MSBuild MSB6001、flutter_tester WebSocket 失败
- Git Bash 下 `/tmp` 与 Python 看到的路径不一致：临时文件一律写工作区相对路径（如 `dist/vX/..json`），别用 `/tmp`
- `dist/` 在 .gitignore（第 34 行），发布说明与产物不入库
