## 修复「我的」页设置区整块消失，发布 v1.6.1

用户报障：「怎么设置 深色 浅色模式 跟随系统 没有了」。

排查结论：不是入口被删，是布局直接崩了。`profile_page.dart` 的
`_quickEntries()` 里三个快捷入口的 `Row` 用了
`CrossAxisAlignment.stretch`（本意是让三张卡片等高），但它被放在
`ListView` 里，纵向约束是无限大，`stretch` 把「无限高」原样传给子卡片，
触发 `BoxConstraints forces an infinite height` 断言。一排布局失败后，
排在它后面的兄弟节点（最近观看、整块设置区）全部不渲染。

这个 bug 在 v1.6.0 之前的版本就已存在，只是用户到 v1.6.0 才注意到。

### 修复

- `_quickEntries` 外层套 `IntrinsicHeight`：先量实际高度再交给 stretch，
  等高效果保留，约束变成有限值
- 设置区容器从带 `BoxDecoration` 的 `Container` 改为 `Material`：
  `ListTile` 的背景与水波纹画在最近的 `Material` 上，中间夹
  `DecoratedBox` 会遮住并抛断言（12 个同类异常）
- 新增 `test/profile_settings_test.dart`（2 项），直接 pump `ProfilePage`
  断言设置区必须包含「主题外观 / 遥控器模式 / 清空观看记录 / 清理缓存 / 关于」

### 关键经验

**widget 测试能抓到肉眼读代码读不出来的布局崩溃。** 之前逐行读
`profile_page.dart`、核对 git log 都确认主题行存在且从未被改过，
但测试一跑就暴露出真实崩溃点。以后遇到「某块 UI 不见了」，
第一反应应该是写 widget 测试 pump 出来，而不是读代码。

另外验证了一条已确定的结论：**Dart AOT 快照里搜不到明文字符串**，
用 `grep` 在 `libapp.so` 里找 UI 文案（连确定存在的「遥控器模式」）
全部 MISSING，这条路走不通。

1. **`flutter build windows` 报「Unable to find suitable Visual Studio
   toolchain」**，但 VS 2022 装在 `C:/Program Files/Microsoft Visual

## TV 首页按参考图重做布局

参考截图形态：顶部横向频道胶囊行 + 海报网格（年份角标、集数角标）。
落地在 `home_page.dart` 的 `_buildTv()`，手机布局走另一条分支不受影响。

### 关键改动

- `_buildTv()`：`Column`（频道条 + `Expanded(IndexedStack)`），不用
  `TabBarView`——遥控器没有「横划」手势，翻页能力等于白给
- `_visited` 集合 + `_selectCategory()`：`IndexedStack` 会实例化全部
  children，7 个分类等于开机并发 7 个请求，未访问的位置返回
  `SizedBox.shrink()` 剪掉
- 非当前页必须 `ExcludeFocus` 摘掉焦点子树：`IndexedStack` 不绘制
  隐藏页，但焦点系统不认「看不见」，遥控器会走进隐藏页
- `DramaCard` 加 TV 年份角标（仅 `isTv` 且 `year > 0`）

### 一个主动砍掉的设计

参考图里还有「排序方式（最新/高分/最热/日热度/周热度/月热度）」和
「更多筛选」。写 `test/api_probe_test.dart` 联网实测了 10 个参数
（`sort`/`order`/`sortType`/`orderBy`/`year`/`area`/`class`/`typeId1`/
`filter`/`isHot`），返回的前 5 条 id 与基准**完全一致**——服务端全部忽略。
摆一排点了没反应的按钮比不摆更糟，所以不做，并在代码里写明原因。

### 测试踩坑（两条都是「假通过」陷阱）

1. **`!timersPending` 全红**：`PagedGrid.initState` 就发请求，Dio 在
   `fetch` 内部会挂一个零时长定时器，用例结束时断言失败。写了一套假
   `HttpOverrides`/`HttpClient` 桩**拦不住**（请求链不止走 dart:io）。
   正解是给 `HomePage` 加 `@visibleForTesting debugLoader`，注入立即返回
   的 loader——布局测试本来就不该联网。
2. **`find.byType` 默认 `skipOffstage: true`**：`IndexedStack` 把非当前页
   标为 offstage，默认查找只数到当前页那 1 个。于是
   `expect(count, lessThan(7))` 恒成立，看着绿其实什么都没验。必须写成
   `find.byType(PagedGrid, skipOffstage: false)` 才是真的在数。
3. 测试窗口默认 800x600，装不下 7 个频道胶囊（总宽近 900），超出的部分
   被裁掉，`tester.tap` 命中不到。TV 用例统一设 1920x1080。

## UI 归一化：设计 token 层（提交 `c5d1080`）

审查实测到的离散程度：**15 种字号、11 种圆角、0 处 reduced motion、0 处卡片读屏语义**。

### 新建 `lib/core/tokens.dart`

- `Ts`：7 级字号，按**角色**命名（caption/bodySm/body/bodyLg/subtitle/title/display），
  不按大小（small/medium）。以后调阶梯值时调用处语义不变。
- `R`：5 级圆角。另留 `R.bar = 2` 给内嵌进度条——2px 是进度条的正确用法，不该并入 sm。
- `Motion`：micro 130 / short 220 / medium 320。
- `motionOf(context, fallback)`：读 `MediaQuery.maybeDisableAnimationsOf`，
  系统开「减少动态效果」时返回 `Duration.zero`，组件瞬间到终态。

替换 140 处字号、46 处圆角。**动态适配值与参数化值有意保留**：
`circular(tv ? 23 : 17)`、`circular(widget.radius)` 这类不该写死。

### 判断边界（避免误报）

`minimumSize: Size(0, 26/28/30)` 看着像触控目标不足，但 Material
`MaterialTapTargetSize.padded` 默认补足到 48dp，且未用 shrinkWrap → **不算问题**。

### 动效只接 5 处 UI 过渡

频道胶囊 / 导航项 / 卡片悬停 / 焦点描边 / 焦点滚动（`Scrollable.ensureVisible`）。
其余 `Duration` 全是业务计时（重试退避、保存防抖、HUD 超时、弹幕飞行、seek），
**不参与 reduced motion**——把防抖时长归零会引发写盘风暴。

### 空态改造

原文只有一行 `return const EmptyView(text: '没有找到相关影片')`，用户无路可走。
现在：搜索空态给热词 `ActionChip` 且文案带上关键词；分类空态给刷新按钮。
`EmptyView` 扩展出 hint/action/icon 三个可选字段，保持向后兼容。

### 踩坑：Python 批量改写把文件写成了 CRLF

`git diff --stat` 显示 9032 行变更，但 `git diff -w` 只有 323 行真正改动。
根因：之前用 `open(p, 'w')` 写文件，Python 在 Windows 上默认 CRLF。
用 `od -c` 确认后批量转回 LF。**已补 `.gitattributes` 钉死 `*.dart text eol=lf`**，
防止复发。诊断口诀：`diff --stat` 与 `diff -w --stat` 数字差一个数量级 → 查换行符。
