### 教训（容易重踩）

1. **`Container(color: ...)` 包 `Row` 会拉出整宽横带**。`Row` 默认 `mainAxisSize.max`，
   在 Stack 的非 positioned 子项里会撑满宽度 → 表现为「暂停时画面上多一条与按钮等高的灰框」。
   用户直接截图报了这个问题。要贴背景就只包按钮本身，用 `Center` + 圆底 + `BoxShadow`。
2. **Hero tag 必须带页面命名空间**。同一部剧会同时出现在多个 Tab（TabBarView 保活相邻页），
   同一路由里两个同 tag 的 Hero 会断言失败。`posterHeroTag(scope, id)` 的 scope 由
   知道自己是哪一页的调用方给；搜索页「全部」是多源混合，tag 还要带 sourceId（不同源 id 会撞号）。
3. **Hero 落点必须在目标页第一帧存在**。详情页要 1 秒才拿到数据，所以加了 `initialCover`
   参数从列表透传，并让 loading 态骨架与最终版式同构（差 10px 都会让转场结束时整页跳一下）。
4. **`PagedGrid.onTap` 加参数会打断所有测试**。改签名后记得同步 `test/load_deadline_test.dart`
   的 `onTap: (_) {}` → `(_, __) {}`。
5. **`CupertinoPageTransitionsBuilder` 在本机 Flutter 版本里不存在**（analyze 报 undefined）。
   `pageTransitionsTheme` 只覆盖 windows/linux/macOS，其余平台走内置默认。
6. **骨架屏替换转圈会让「转圈断言」的测试失效**。`load_deadline_test` 里
   `find.byType(CircularProgressIndicator)` 改成 `find.byType(PosterGridSkeleton)`。
